# Scientific Figures

`cell_perturbation_restoration.*` is the recording-ready scientific figure for
the Protein Hinge MVP.

It is generated by:

```bash
python3 scripts/make_cell_perturbation_figure.py
```

The script verifies all source hashes before plotting and writes:

- `cell_perturbation_restoration.png`
- `cell_perturbation_restoration.svg`
- `cell_perturbation_restoration.pdf`
- `cell_perturbation_restoration.provenance.json`

The same PNG is copied to `site/assets/` for the dashboard Figure tab.
